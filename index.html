【webCV】削除日延長バルス

素材検索結果（元素材・OA素材）またはコンテナ内の素材に対し、削除日を延長方向にのみ更新し、必要に応じて預入日も一括設定するブックマークレットです。

【初回のみ】ブックマークレットを登録

  1. Chrome / Edge のブックマークバーを表示します（Ctrl+Shift+B）。
  2. 下のボタンをブックマークバーへドラッグ＆ドロップします。
削除日延長バルス

登録後の更新作業は不要です。ツール起動時に毎回最新の tool.js を読み込むため、管理者側で更新すると次回起動時から自動的に最新版が使用されます。

使い方

  1. webCVで、素材検索結果（元素材・OA素材のいずれか、または両方）を表示するか、対象コンテナを開いて素材を表示します。サムネイル表示・リスト表示のどちらでも利用できます。
  2. 画面右上のグループが「CV収録送出」になっていることを確認します。
  3. 登録した「削除日延長バルス」をクリックします。
  4. 処理モードと日付を確認し、「バルス！！」を押します。
  5. 進捗・各素材の結果をツール画面で確認します。
2画面モード（素材検索＋コンテナの分割表示）では実行できません。実行中は処理完了まで当該webCVタブを閉じたり、リロードしたりしないでください。

主な仕様

  • 起動時の削除日・預入日は空欄。削除日は入力必須で、入力されるまで赤枠表示
  • 「削除日＋預入日」モードでは預入日も入力必須となり、空欄の間は赤枠表示
  • 削除日・預入日は、カレンダーアイコンだけでなく入力欄のクリックでも日付選択カレンダーを表示
  • 削除日・預入日はツール実行日以降のみ選択可能（過去日は選択不可）
  • 削除日更新ルール: 指定削除日 ≧ 既存削除日 の場合のみ処理（前倒しは素材全体をスキップ）
  • 既存削除日が未設定の素材は、削除日・預入日とも更新せずスキップ
  • 素材検索画面では、元素材・OA素材の両方を処理対象として収集（元素材のみ／OA素材のみの検索にも対応）
  • Error素材は最優先で除外
  • 素材タイトルが空の素材は、画面・素材種別・サムネイル種別を問わず更新せずスキップ
  • 素材タイトル空かつ実サムネイル枠のsrc属性が未設定／空の素材は、結果上「削除済み」としてスキップ
  • Not Filed サムネイルでも、素材タイトルがありErrorでなければ通常素材と同じ処理対象
  • リスト表示では「素材タイトル」列の表示が必須。列を確認できない場合は処理を開始しない
  • 素材検索で元素材／OA素材セクションが折りたたまれている場合は、展開を案内して処理を開始しない
  • 日付ルール: 削除日 > 預入日
  • モード: 「削除日のみ」または「削除日＋預入日」
  • 預入日はアーカイブ対象で入力可能な素材のみ更新
  • 素材検索／コンテナのサムネイル表示・リスト表示に対応
  • 素材番号は専用DOMから取得し、FC/FA等のプレフィックスや採番世代に依存せず、表示用ハイフンを除去した半角英数字として正規化
  • 未知の素材番号形式でも素材自体は認識件数から落とさず、番号不明として結果一覧に残す
  • Error素材、重複素材、番号不明素材、プレビュー起動要素不明素材は結果一覧に理由付きで表示
  • 処理対象が100件以上の場合は、長時間処理になる可能性を画面上で警告
  • 結果一覧では素材番号の右側に素材タイトルを表示。長いタイトルは省略表示し、マウスオーバーで全文を確認可能
  • 結果一覧の左端チェックボックスで延長対象素材を選択可能。処理可能素材は初期状態ですべてON、前提条件でスキップとなる素材はOFF・操作不可
  • チェック列のヘッダ操作で処理可能素材を全選択／全解除可能。選択0件では実行不可で、進捗・100件警告は選択件数を基準に表示
  • 実行直前に対象を再確認し、起動時から変化していた場合は処理を中断
